description=[url=https://community-owned-workshop.github.io/wiki/][img]https://raw.githubusercontent.com/community-owned-workshop/wiki/refs/heads/main/assets/banner-title-seals-scrap-mechanic.png[/img][/url]
description=
description=[h2]Why this exists[/h2]
description=
description=Traditional Survival file mods often install themselves by directly editing files inside [i]Scrap Mechanic\Survival[/i]. That works for one mod, but multiple installers overwrite each other's JSONs, Lua files, recipes, ShapeSets, or icon  atlases.
description=
description=The bootstrapper lets participating mods describe their changes in a [i]bootstrap.json[/i]. On startup it restores clean  vanilla merge targets and then applies all installed bootstrap-enabled mods together.
description=
description=
description=[h2]What it does[/h2]
description=[list]
description=[*] Detects the installed Scrap Mechanic version
description=[*] Keeps a version-specific vanilla backup of only the files it modifies
description=[*] Discovers bootstrap-enabled mods
description=[*] Restores the clean merge targets before every run
description=[*] Applies all mod registrations from scratch
description=[*] Detects conflicting UUID / resource claims instead of silently overwriting another mod
description=[*] Allocates shared icon-atlas slots centrally
description=[*] Deletes only [b]Cache\Bundle\core_data.cbo[/b] when generated content changes
description=[*] Writes diagnostics to [b]bootstrapper.log[/b]
description=[/list]
description=
description=[h2]Installation[/h2]
description=
description=Before the first run, verify Scrap Mechanic's files through Steam. The first version-specific backup must be created  from clean vanilla files.
description=
description=Then add this to the Launch Options in Steam:
description=
description=[code]
description=(SteamWorkshopFolder)\387990\3784073427\Start-ScrapMechanic.cmd %command% 
description=[/code]
description=
description=[b]Example:[/b]
description=
description=[i]([b]387990[/b] is the ID for Scrap Mechanic, [b]3784073427[/b] is the ID of this mod.)[/i]
description=
description=[code]
description=C:\Program Files (x86)\Steam\steamapps\workshop\content\387990\3784073427\Start-ScrapMechanic.cmd %command% 
description=[/code]
description=
description=
description=[quote]
description=‼️ [b]If your path has spaces, you need to put [url=https://en.wikipedia.org/wiki/Quotation_mark]double quotes[/url] around 
description=them. Unfortunately, SteamCMD won't let me publish this description with double quotes in it, so I can't provide a 
description=complete example here.[/b]
description=[/quote]
description=
description=If you want to test the bootstrapper directly, go to its folder and execute:
description=
description=[code]
description=.\Bootstrapper.ps1 -GamePath (SteamFolder)\steamapps\common\Scrap Mechanic -NoLaunch
description=[/code]
description=
description=[b]Example:[/b]
description=
description=[code]
description=.\Bootstrapper.ps1 -GamePath C:\Program Files (x86)\Steam\steamapps\common\Scrap Mechanic -NoLaunch
description=[/code]
description=
description=
description=[h2]Cache[/h2]
description=
description=When generated content changes, the bootstrapper removes only [i]Cache\Bundle\core_data.cbo[/i]. Do not delete the complete Scrap Mechanic [b]Cache[/b] directory (I learned that the hard way).
description=
description=
